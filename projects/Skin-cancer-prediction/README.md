# Skin cancer image classifier

> **تنبيه طبي:** هذا المستودع مثال هندسي/تعليمي فقط، وليس أداة تشخيص أو جهازًا طبيًا. لا تستخدم أي ناتج لاتخاذ قرار طبي؛ راجع طبيبًا مؤهلًا.

## الحالة الحالية

تمت مراجعة `skincancer.ipynb` وإصلاح مسارات التشغيل، تقسيم البيانات، قابلية إعادة الإنتاج، المقاييس، والتحقق من المدخلات. لا توجد صور بيانات أو أوزان نموذج مضمنة في المستودع، لذلك لا يمكن الإبلاغ عن أداء أو تشغيل تدريب كامل من هذه النسخة.

## البيانات المتوقعة

ضع البيانات خارج Git في هذا الشكل:

```text
train/
  <class-a>/*.jpg
  <class-b>/*.jpg
test/
  <class-a>/*.jpg
  <class-b>/*.jpg
```

يجب أن يحتوي `train/` و`test/` على مجلدي الفئات نفسيهما، وأن تكون هناك فئتان بالضبط. يتطلب كل مجلد فئة في `train/` خمس صور مدعومة على الأقل حتى ينتج تقسيم التحقق 20% صورة واحدة على الأقل، كما يتطلب `test/` صورة واحدة على الأقل لكل فئة. الصور المدعومة هي امتدادات Keras المعتادة: `bmp` و`jpeg` و`jpg` و`png` و`ppm` و`tif` و`tiff`. لا يخلط الـ notebook مجلد الاختبار مع التحقق: يُقسّم `train/` عشوائيًا بصورة ثابتة إلى تدريب/تحقق، ويُستخدم `test/` مرة واحدة بعد انتهاء التدريب. هذا لا يثبت غياب تسرب على مستوى المريض؛ يلزم معرّف مريض أو فحص تكرارات مستقل لذلك.

يمكن تحديد جذر البيانات:

```bash
export SKINCANCER_DATA_ROOT=/path/to/dataset
```

والافتراض الافتراضي هو المجلد الحالي. يُوقف الـ notebook التنفيذ برسالة واضحة عند غياب المجلدات أو عدم تطابق الفئات. لا تُخزّن الصور أو النماذج الناتجة في Git؛ مسار النموذج الافتراضي هو `artifacts/skin_cancer_classifier.keras` ويمكن تغييره عبر `MODEL_PATH` (ويجب أن ينتهي بـ `.keras` أو `.h5`). بعد الحفظ، يعيد الـ notebook تحميل النموذج ويتحقق من شكل الإدخال/الإخراج.

## التشغيل

1. أنشئ بيئة Python مناسبة وثبّت الاعتماديات: `python -m pip install -r requirements.txt`.
2. ضع البيانات وفق البنية أعلاه.
3. شغّل خلايا `skincancer.ipynb` بالترتيب.
4. للتحقق من صورة اختيارية بعد التدريب: `export PREDICT_IMAGE=/path/to/image.jpg`.

الـ notebook يطبع **accuracy وloss وclassification report وconfusion matrix وROC-AUC عند توفر الفئتين** على مجموعة الاختبار. لا تعتبر هذه المقاييس صالحة سريريًا دون بيانات مستقلة وموسومة جيدًا وتصميم تقييم على مستوى المريض.
